# Jenkins CI/CD Pipeline with Golang

## Project Overview

This project demonstrates a basic Continuous Integration and Continuous Deployment (CI/CD) pipeline using Jenkins, Docker, Git, GitHub, and Golang.

## Tech Stack

- Golang
- Jenkins
- Docker
- Git
- GitHub

## Project Structure

```
jenkins-golang-cicd/
├── Dockerfile
├── Jenkinsfile
├── go.mod
├── main.go
└── .gitignore
```

## Pipeline Workflow

1. Checkout source code from GitHub
2. Build Docker image
3. Run Docker container
4. Verify successful execution
